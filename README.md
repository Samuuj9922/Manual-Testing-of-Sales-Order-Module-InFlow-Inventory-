## 📖 Project Overview

This repository showcases a manual testing project conducted on the **Sales Order Module** of the **InFlow Inventory** application.

The project was carried out using the **Software Testing Life Cycle (STLC)**, beginning with requirement analysis and continuing through test planning, test environment setup, test case development, test execution, defect reporting, and project documentation.

The objective was to validate the functionality of the Sales Order module against the Software Requirements Specification (SRS) and identify any deviations between the expected and actual system behavior.

---

## 🎯 Objective

To perform comprehensive manual testing of the Sales Order module by designing and executing test cases based on the provided SRS and documenting defects identified during testing.

## 🔄 Software Testing Life Cycle (STLC)

### 1. Requirement Analysis

- Reviewed the Software Requirements Specification (SRS).
- Understood the business requirements and expected functionality of the Sales Order module.


### 2. Test Planning

- Planned testing activities.
- Identified testing scope and approach.
- Distributed testing tasks among team members.
- Coordinated project progress and reviewed deliverables as the Team Lead.

### 3. Test Environment Setup

- Set up the application and testing environment.
- Verified that the application was ready for manual testing.


### 4. Test Case Development

- Designed positive and negative test scenarios.
- Prepared detailed test cases based on the SRS.
- Reviewed test cases prepared by team members.

### 5. Test Execution

- Executed manual test cases.
- Compared actual results with expected results.
- Recorded test execution status as Pass or Fail.


### 6. Defect Reporting

- Identified and documented software defects.
- Logged defects with proper Bug ID and description.
- Assigned appropriate Severity and Priority.
- Documented Expected Result and Actual Result.
- Attached supporting screenshots where required.


### 8. Test Closure

- Reviewed completed testing activities.
- Compiled project documentation.
- Prepared testing reports and project presentation.
- Summarized testing activities and project outcomes.
